StudioMate 教室管家

給健身房、瑜珈、舞蹈、拳擊教室用的課程預約與會員管理系統。從排課、約課、扣堂、LINE 提醒、線上售卡和電子發票，到退費、門禁、零售、員工排班，一套全包。

功能總覽

系統做得到的事

排課與預約

  • 固定課表自動排課，也能臨時加開或取消整堂課（取消會自動退堂並通知會員）
  • 線上預約，額滿時排候補，有人取消就自動遞補
  • 可設取消截止時間，晚取消照樣扣堂
  • 私人課依教練每週可約時段預約
  • 場地租借，會自動避開已經排課的時段
  • 直播課連結、行事曆訂閱（iCal）
  • 會員端可安裝到手機主畫面，提醒可同時推送到手機

方案與會籍

  • 堂數卡、期限卡（可設每日上限）、單堂課
  • 可限定方案只能上哪些課程類型
  • 凍結延期、補堂、作廢
  • 體驗方案限首次購買

點名與現場

  • 手動點名，或下課後自動記為出席
  • QR code 自助簽到
  • 未到次數達上限時，暫停該會員的線上預約
  • 會員條款線上同意，條款改版後須重新同意

收款與發票

  • 綠界信用卡付款（可分期、可每月自動扣款），或 LINE Pay；付款成功後自動開通方案
  • 銀行轉帳：會員回報帳號後五碼，櫃檯審核
  • 售卡時自動開立電子發票，方案作廢時發票一併作廢
  • 支援手機條碼、自然人憑證、捐贈、統編

LINE 與行銷

  • LINE 自動提醒：上課前、方案快到期、堂數不足、候補遞補成功、停課
  • 依條件篩選名單（例如很久沒來上課的會員），群發 LINE 訊息
  • 折價券、轉介紹獎勵與介紹人排行

退費、轉讓與合約

  • 退費自動試算應退金額，處理發票作廢或折讓
  • 會籍轉讓給其他會員，可收手續費
  • 預收款履約保障資訊與尚未履約金額報表
  • 電子合約，線上或櫃檯手寫簽名

門禁、置物櫃與體測

  • 會員動態入場 QR code，櫃檯掃碼或閘門自動判斷
  • 入場時自動簽到當天預約的課
  • 置物櫃出租、續租與到期提醒
  • 體組成量測紀錄，會員手機看得到變化

零售與員工

  • 商品收銀、庫存、進貨與盤點，開立電子發票
  • 員工班表、上下班打卡、出勤工時
  • 教練請假與代課，自動通知會員
  • 階梯式教練抽成

自動行銷與分析

  • 生日祝福、久未到訪喚回，可附折價券
  • 公告推播、滿意度問卷與下課評價
  • 續約率、流失、熱門時段、課程與教練排行
  • 營收含商品、置物櫃、場地並扣除退費

營運管理

  • 今日課表、快到期名單、堂數不足名單、近 30 天出席率
  • 營收報表，可依月份、方案、付款方式查看
  • 教練薪資＝鐘點費＋人數加給＋業績抽成
  • 員工帳號，可依功能模組設定權限
  • 會員資料可用 CSV 匯入（先預覽再寫入）；會員、銷售、上課紀錄、薪資都能匯出
產業對照

跟台灣現有系統比，對齊到哪裡

比較對象是台灣常見的 5 套健身／場館管理系統：17FIT、BookFast、Fitbutler 健身管、MoHot、璿恩。

結論：主流功能已全部具備。第三版補上了退費與轉讓、預收款履約保障、定期定額、分期、LINE Pay、電子合約、階梯抽成、請假代課、員工班表與打卡、門禁、置物櫃、體組成、商品零售、營運分析、自動行銷、公告與問卷。和同業相比，LINE 提醒不另外收費（BookFast 的 LINE 推播要加購），教練薪資算法也比較完整。

還有兩項只做到一部分：街口支付沒有串接、InBody 數據要手動輸入。會員端是可以安裝到手機主畫面的 Web App，有推播通知，但沒有上架 App Store。另外有兩項需要教室自己對外完成：信託或履約保證要跟銀行簽約，閘門硬體要請設備廠商串接系統提供的 API。

上線前準備

要開始用新功能，教室需要準備的事

  1. 金流

    向綠界申請定期定額與分期

    這兩項要先在綠界開通，再到「教室設定 → 線上購買與發票」填入分期期數，並在方案勾選「定期定額」。

  2. 申請 LINE Pay 商店

    取得 Channel ID 與 Channel Secret Key，填到「教室設定 → 線上購買與發票 → LINE Pay」。

  3. 法規

    與銀行簽訂信託或履約保證

    簽約後到「教室設定 → 退費與履約保障」填寫銀行與方式。報表裡的「預收款」就是向銀行申報額度時要用的金額。

  4. 確認退費手續費與合約內容

    預設合約只是範本。請依教室實際規定修改退費、轉讓條款，手續費比例也要跟會員條款一致，必要時請法律專業人士審閱。

  5. 現場

    櫃檯掃碼器與閘門

    USB 掃碼器接上櫃檯電腦就能用。要接閘門或電子鎖，請到「門禁入場 → 閘門裝置」新增裝置，把網址與金鑰交給設備廠商。

  6. 設定員工帳號對應的教練

    在「帳號權限」把教練的帳號對應到教練資料，教練就能在課表替自己的課請假。
